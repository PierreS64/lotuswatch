# LotusWatch v0.1 Scope

## Goal

Inspect basic website transport and HTTP security configuration and
produce understandable findings.

## Included

- Target validation
- HTTP-to-HTTPS redirect detection
- TLS certificate expiration
- Selected HTTP security headers
- Console and JSON output
- Timeouts and understandable error messages

## Excluded

- Exploitation
- Credential testing
- SQL injection and XSS probing
- Brute force
- Port-range scanning
- Authentication crawling
- Denial-of-service testing
